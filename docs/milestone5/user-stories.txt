EPIC 2 – AUTHENTICATION
==========================================================

US11 (TPS-69)
As a registered user,
I want to securely log out of the Civic Services Platform,
So that my account remains protected and unauthorized users cannot access my session.

US12 (TPS-68)
As a system administrator,
I want the system to enforce role-based access control,
So that citizens, administrators, and field workers can access only the features and information that are authorized for their roles.

US13 (TPS-67)
As a field worker,
I want to log into the Civic Services Platform,
So that I can view my assigned repair tasks, update repair progress, and mark completed work efficiently.

US14 (TPS-66)
As an administrator,
I want to log into the Civic Services Platform,
So that I can manage complaints, assign repair tasks, monitor complaint progress, generate reports, and administer the platform securely.

US15 (TPS-65)
As a citizen,
I want to log into the Civic Services Platform,
So that I can securely access my dashboard, submit complaints, track complaint status, and manage my account.

US16 (TPS-64)
As a citizen,
I want to create an account,
So that I can securely access the platform and manage my complaints.

EPIC 3 – CITIZEN COMPLAINT MANAGEMENT
==========================================================

US17 (TPS-77)
As a citizen,
I want to provide feedback and rate the completed repair work,
So that I can share my satisfaction with the quality and timeliness of the service provided.

US18 (TPS-76)
As a citizen,
I want to receive notifications whenever the status of my complaint changes,
So that I remain informed about the progress of my complaint without having to check the system frequently.

US19 (TPS-75)
As a citizen,
I want to cancel my submitted complaint,
So that I can withdraw complaints that are no longer valid or have been resolved before repair work begins.

US20 (TPS-74)
As a citizen,
I want to edit my submitted complaint before it is assigned to a field worker,
So that I can correct any incorrect or incomplete information.

US21 (TPS-73)
As a citizen,
I want to view the complete details of a reported complaint,
So that I can verify the submitted information and monitor the progress of my complaint.

US22 (TPS-72)
As a citizen,
I want to view the history of all my submitted complaints,
So that I can monitor my previous reports and their current status without submitting duplicate complaints.

US23 (TPS-71)
As a citizen,
I want to track the status of my reported complaint,
So that I know the progress of the repair work and when the issue is expected to be resolved.

US24 (TPS-70)
As a citizen,
I want to report a pothole by submitting its details,
So that the municipal authority can repair it promptly and improve road safety.
