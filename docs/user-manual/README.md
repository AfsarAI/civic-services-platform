# User Manual

This folder contains end-user documentation for the Civic Services Platform.

## Roles

### Citizen
- Register an account
- Submit a complaint (pothole, streetlight, etc.)
- Track the status of submitted complaints
- Provide feedback on resolved issues
- View complaint history

### Administrator
- Log in with admin credentials
- View all submitted complaints
- Assign complaints to field workers
- Update complaint status
- Generate reports
- Manage user accounts

### Field Worker
- Log in with field worker credentials
- View assigned complaints
- Update repair progress
- Mark complaints as resolved
