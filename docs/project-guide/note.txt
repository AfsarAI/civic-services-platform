Branches
main

Production-ready code only.
Never develop directly on main.
Only merge after:

Code Review
Successful Testing
Sprint Completion


dev

Integration branch.
Every feature is merged into dev.
The team tests the complete application here.


Feature Branches
Create one feature branch per Jira Story or feature.
Examples:
feature/<rollno>-<jiraid>-authentication

feature/<rollno>-<jiraid>-report-pothole

feature/<rollno>-<jiraid>-citizen-dashboard


Don't create one branch per developer.
Create one branch per feature.
