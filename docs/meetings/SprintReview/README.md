# Sprint Review Meeting Notes

This folder contains Sprint Review (Demo) meeting notes.

## Template

Each Sprint Review file should be named `sprint-N-review.md` and include:

```markdown
# Sprint N — Sprint Review

**Date:** YYYY-MM-DD
**Attendees:** [team + stakeholders]
**Scrum Master:** [name]

## Sprint Goal Review

**Goal:** [sprint goal]
**Achieved:** Yes / Partially / No

## Demonstrated Features

| Feature | Demonstrated By | Stakeholder Feedback |
|---|---|---|
| | | |

## Accepted Stories

| Story ID | Title | Points |
|---|---|---|
| | | |

## Not Completed

| Story ID | Title | Reason | Carry Over? |
|---|---|---|---|
| | | | |

## Stakeholder Feedback

[Notes from stakeholders]

## Updated Product Backlog

[Link to Jira backlog or list changes]
```
